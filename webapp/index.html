Dataset y metodología

⇧

Carga un nuevo dataset

Selecciona o arrastra un archivo CSV con la estructura de órdenes de trabajo del análisis GMAO.

Columnas requeridas: Tipo_mantenimiento, Equipo, Downtime_h, Horas_mano_obra y Costo_total_CLP. Para calcular MTTR incluye Estado, Fecha_inicio y Fecha_fin. Puedes arrastrar el CSV hasta aquí.
i

Metodología. Los indicadores se calculan directamente desde las filas seleccionadas. Las filas duplicadas exactas se eliminan; las OT se cuentan de forma única cuando existe el campo OT. El MTTR es el promedio de horas entre inicio y fin para órdenes correctivas cerradas con fechas válidas y duración positiva. Se admiten fechas DD-MM-AAAA e ISO; los campos numéricos aceptan coma o punto decimal.
